# ⌨️ TypeChallenge — JavaScript Word Game

A browser-based typing game where players test their 
accuracy on words and phrases. Built with vanilla 
JavaScript, no frameworks or libraries.

## 🎮 How to Play

1. Choose a game mode — **words** or **phrases**
2. Type exactly what is displayed on screen
3. The game checks your input in real time
4. See your final score at the end
5. Share your score with a friend and challenge them to beat it

## ✨ Features

- Two game modes : words and phrases
- Real-time input validation
- Score tracking throughout the game
- Share score via popup and invite friends to play

## 📁 Project Structure

## 🔧 Technologies

- HTML5
- CSS3
- JavaScript (vanilla)

## 🚀 How to Run

No installation needed. Simply open `index.html` 
in your browser.
